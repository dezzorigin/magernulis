# USER-GUIDE.md — Panduan Pengguna Magernulis

## Membuka studio

Buka https://magernulis.pages.dev lalu klik **Buka Studio**, atau
langsung ke https://magernulis.pages.dev/studio/.

## 1. Mengisi catatan

Panel kiri (tab **Teks & Isi**):

1. **Template preset** — klik Algoritma, Matematika, Sejarah, atau Resume
   Buku untuk mengisi seluruh catatan dengan contoh. Edit isinya sesudahnya.
2. **Header identitas** — isi Topik, Nama, NIM, dan Tanggal (tombol
   **Hari Ini** mengisi tanggal hari ini). Centang "Tampilkan Kotak Header"
   untuk menyembunyikan/menampilkan header di kertas.
3. **Isi Cornell** — Pertanyaan (kolom kiri), Catatan (kolom kanan),
   Rangkuman (bawah). Ketikanmu langsung tampil di kertas.

Tombol atas: **Contoh** mengisi catatan contoh Algoritma;
**Reset** mengosongkan form (minta konfirmasi dulu);
**Simpan Draft** mengunduh `.json`; **Buka Draft** membuka `.json` tadi.

## 2. Mengatur gaya

Tab **Gaya Kertas**: pilih kertas (Folio Bergaris, Grid Binder, Vintage
Cream, HVS Putih), tinta pulpen (Biru, Gel Hitam, Classic Navy, Merah
Catatan), backdrop meja (Dot Grid, Meja Kayu, Minimalis), dan efek camera
scanner (tanpa filter, Clean, Shadow, Warm, Photocopy).

Tab **Humanizer**: geser tingkat ketidakrapihan (Rapi → Acak) atau klik
**Gacha Acak Tulisan Humanis** untuk mengocok kemiringan kata.

Tab **Font & Gaya**: pilih 1 dari 17 font tulisan tangan, atur ukuran
font (0,9–1,8rem) dan jarak baris (1,1–2,0).

## 3. Mengelola halaman

Tab **Halaman**: beri nama tiap lembar, klik **Tambah Kertas Baru**
(halaman lanjutan otomatis tanpa header), atau **Hapus Kertas Ini**
(minta konfirmasi; minimal 1 lembar harus tersisa). Pindah halaman lewat
pill di bar bawah atau daftar di panel ini.

## 4. Mengekspor

Klik **Bagikan / Unduh** di kanan atas:

- **Unduh PNG (Halaman Ini)** — gambar HD halaman aktif.
- **Unduh Paket ZIP (Semua Halaman)** — satu ZIP berisi PNG tiap halaman.
- **Ekspor PDF HD (Halaman Ini / Semua Halaman)** — dokumen A4.
- **Cetak Dokumen** — mencetak hanya kertasnya (UI disembunyikan).
- **Simpan / Buka Project (.json)** — draft untuk dibuka lagi.
- **Salin Gambar ke Clipboard** — tempel (Ctrl+V) ke dokumen lain.

## 5. Tampilan studio

- **Zoom**: tombol − / +, slider 30–150%, tombol **Fit** (100%).
- **Layar penuh**: tombol di bar bawah.
- **Tema**: tombol Dark/Light di kanan atas; pilihan tersimpan di browser.
- **Sembunyikan panel**: tombol panah di kepala panel kiri.

## Privasi

Semua catatan diproses di browser kamu. Tidak ada akun, tidak ada server,
tidak ada yang diunggah. Tema tersimpan lokal; draft hanya ada kalau kamu
mengunduh `.json`-nya sendiri.
